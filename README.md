🧮 CalcMate

Where Numbers Meet Clarity

CalcMate is a clean, beginner-friendly desktop calculator built with pure Python and Tkinter. No external libraries, no complicated setup. Just readable code that turns core programming concepts into a tool you can actually use.

✨ Features
Core arithmetic: addition, subtraction, multiplication, and division
Modern dark interface: a navy color scheme with red operator keys and a cyan equals button
Fixed, compact window: a focused 400×600 layout that stays tidy on any screen
Clean, object-oriented code: one Calculator class with separate methods for the display and the buttons, so it is easy to read and extend
Zero dependencies: built entirely on Python's standard library
🎯 Why CalcMate?

Most beginners learn variables, functions, and classes in isolation. CalcMate shows how they fit together in one working application: handling user input, updating a display, and organizing code into a class.

It works well as:

a first real project after learning Python basics
a reference for building simple GUIs with Tkinter
a starting point for your own features, such as a history panel, keyboard support, or scientific functions
🚀 Getting Started
Prerequisites
Python 3.x
Tkinter (bundled with Python on Windows and macOS)

On some Linux distributions, install it with sudo apt install python3-tk.

Run it
bash
# Clone the repository
git clone https://github.com/puspitapuja19/ClacMate.git

# Move into the project folder
cd ClacMate

# Launch the calculator
python Calculator_1.py

Close the calculator window to stop the program.
